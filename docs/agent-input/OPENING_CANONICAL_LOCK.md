# OPENING_CANONICAL_LOCK

Fonte autoral: `docs/ATLAS_CAMADA_PUBLICA_EXPERIENCIA_CANONICA_20260829.md`, secções 3 e 3.1–3.4.

Este ficheiro é um recorte de execução para uma única alteração. Não substitui a fonte integral.

## Requisito bloqueado

A abertura pública deve começar por:

`PRETO → SELO → TOQUE → COSMICOXES`

- **PRETO:** ecrã totalmente negro; nenhum logótipo editorial, menu, slogan, card ou instrução visual compete com o vazio.
- **SELO:** o Selo Atlas surge quase imperceptível como marca de água/limiar, não como botão convencional; continua activável por foco/teclado e touch.
- **TOQUE:** toque, gesto, clique ou activação por teclado faz o selo desaparecer; não abre uma secção, altera o estado do mundo.
- **COSMICOXES:** só depois do toque nasce o campo cósmico reactivo já existente.

## Limites desta alteração

- Não alterar o conteúdo interno de COSMICOXES nem a progressão posterior nesta execução.
- Não inventar texto, asset, território, festa, coordenada, curadoria ou pergunta.
- Usar somente o asset já existente `assets/selo-atlas.png`.
- Preservar `prefers-reduced-motion`, teclado, touch e pointer.
- Não mostrar cabeçalho institucional antes de a dramaturgia o permitir.
- Não publicar nem tocar em Sitejet/FTPS/cPanel.
- Alterar apenas o mínimo em `experience-machine.js`, `index.html`, `atlas.js`, `styles.css` e, se indispensável, um teste.
