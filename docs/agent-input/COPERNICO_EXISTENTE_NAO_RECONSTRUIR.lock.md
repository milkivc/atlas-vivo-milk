# LOCK OPERACIONAL — COPÉRNICO JÁ EXISTE

Instrução autoral directa de 2026-09-02.

1. O globo canónico do Atlas Vivo MILK chama-se COPÉRNICO.
2. O código do COPÉRNICO já existe e deve ser localizado, lido, preservado e integrado.
3. É proibido reconstruir, substituir, redesenhar ou inventar um novo globo.
4. Os dados territoriais públicos também já existem e devem ser recuperados das bases canónicas, respeitando os gates de publicação e direitos.
5. Qualquer workflow/candidato anterior que tente materializar um globo substituto fica supersedido por este lock.
6. Não publicar em produção até o COPÉRNICO original e as bases aprovadas estarem integrados e testados.
